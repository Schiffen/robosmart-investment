# kaleido renders Plotly charts to PNG and is DELIBERATELY NOT PINNED HERE as a
# hard requirement of the feature — report.py treats it as optional and emits a
# complete, chartless report when it is missing. Three reasons it cannot be
# trusted as a dependency:
#
#   * 0.2.1 ships no macOS arm64 binary. It installs cleanly, then fails at
#     render with "./bin/kaleido: No such file or directory".
#   * 1.x is incompatible with Plotly 5.24's fig.to_image(); only kaleido's own
#     calc_fig_sync() works with a 5.x figure, which is what report.py calls.
#   * 1.x drives a REAL CHROME process, which Streamlit Community Cloud has
#     not got and should not be made to download mid-demo.
#
# Install it locally to get charts in the PDF — which is the machine where the
# report's figures are worth generating anyway:
#     .venv/bin/pip install "kaleido>=1.0"
kaleido>=1.0; platform_system != "Linux"
